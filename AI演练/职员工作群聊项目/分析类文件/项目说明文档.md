# 职员各部门工作交流系统 — 项目说明

> 版本：V2.1 · 2026-08-21 · 面向了解项目整体概况的非开发读者，对系统功能按模块做简要说明。

---

## 一、项目简介

一套面向企业的 **职员工作交流系统**，支持职员登录后参与 **部门群聊、全员群聊、一对一的私聊**，同时提供员工信息管理、分类统计、禁言管理与总裁任免管理层等管理功能。

在原「职工信息管理系统」（员工增删改查、查询、统计）基础上升级而来，新增了登录鉴权、三级角色权限、群聊、私聊、个人中心、禁言、总裁管理等能力。

## 二、技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + Vite + Element Plus + ECharts |
| 后端 | FastAPI + SQLAlchemy |
| 数据库 | MySQL |

## 三、角色权限

系统内有三种角色，权限逐级递增：

| 角色 | 说明 |
|---|---|
| **普通职员**（STAFF） | 可使用个人中心、群聊、私聊 |
| **管理部门职员**（MANAGER） | 在普通职员基础上，可管理员工、查看统计、执行禁言 |
| **总裁**（PRESIDENT） | 在管理部门职员基础上，可任免管理部门职员 |

> 登录账号为**职员姓名**（英文不区分大小写）或**员工编号**，初始密码 `123456`。

## 四、功能模块说明

### 1. 登录模块

登录鉴权入口。支持用职员姓名或员工编号登录，登录成功后获得会话凭证（token）；未登录访问系统会自动跳转登录页。系统根据角色自动分发首页：普通职员进群聊，管理层进信息面板。

### 2. 个人中心

职员个人资料维护。可查看自己的信息、修改邮箱和电话、修改密码、上传图片头像（支持 JPG/PNG/GIF/WebP，≤5MB）。

### 3. 群聊模块

多人交流功能（消息持久化保存）。每个职员自动拥有两个群：
- **部门群聊**：仅同部门职员可见、可发言；
- **全员群聊**：全体职员可参与。

支持分页加载历史消息，页面每 5 秒轮询一次新消息。被禁言的职员无法在群聊中发言。

### 4. 私聊模块

职员一对一聊天，消息持久化保存。可从联系人列表选择任意职员发起私聊；私聊**不受禁言限制**。会话列表按最近消息排序（**新消息置顶**），收到新消息显示**未读红点与数量**（包括侧边栏「私聊」入口的角标），打开会话即标记已读。

### 5. 员工管理模块（管理层）

对职员信息进行管理：新增普通职员（默认密码 `123456`，账号=姓名且唯一）、编辑、删除、按 ID 查询，以及多条件组合查询（姓名/部门/职位/薪资区间/入职日期）+ 分页。

### 6. 信息面板模块（管理层）

数据看板。仪表盘汇总员工总数、部门数、职位数、薪资均值/极值，并按部门、职位、入职年份三个维度展示分布，供管理层掌握组织概况。

### 7. 禁言管理模块（管理层）

纪律管理。管理层可对职员发起限时或永久禁言；禁言期间该职员不能群聊发言，但可以查看群聊、正常私聊。可查看当前生效的禁言列表并随时解除。

### 8. 总裁管理模块（总裁）

权限管理。仅总裁可用，负责管理部门职员的任免：查看管理部门名单、授予普通职员管理权限、撤销管理权限。
