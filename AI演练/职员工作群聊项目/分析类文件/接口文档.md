# 职员各部门工作交流系统 — 接口文档

> 版本：V2.1 · 2026-08-18 · 覆盖登录/角色/个人中心/群聊/私聊（含未读/会话置顶）/禁言/总裁管理/员工管理/统计全部接口。

---

## 一、通用说明

- **Base URL**：`http://127.0.0.1:8000/api/v1` · 数据格式 JSON · 编码 UTF-8
- **鉴权**：除 `/auth/login` 外均需 `Authorization: Bearer <token>`（登录返回）
- **分页参数**：`page`（≥1，默认 1）、`page_size`（1~100，默认 10/20），消息类分页返回 `{total, items}`
- **错误响应**：`{ "code": <HTTP码>, "message": "<中文提示>" }`

**错误码**：`401` 未登录/凭证失效 · `403` 无权限 · `404` 资源不存在 · `422` 参数校验失败 · `500` 服务器内部错误

**角色**：`STAFF` 普通职员 · `MANAGER` 管理部门职员 · `PRESIDENT` 总裁

## 三、接口详解

### 认证 / 个人中心（1~6）

**1. POST `/auth/login`**
- body：`{username, password}`；`username` 为**姓名**（英文不区分大小写）或**员工编号**
- 成功 `200`：`{token, user}`（user 见「用户对象」）；失败 `401`「账号或密码错误」

**2. POST `/auth/logout`** → `200`（token 为无状态签名，前端清除即可）

**3. GET `/auth/me`** → `200` 用户对象

**4. PUT `/me`** body（均可选）：`{EMAIL, PHONE_NUMBER}` → `200` 更新后用户对象

**5. PUT `/me/password`** body：`{old_password, new_password}` → `200` `{message}`；原密码错误 `400`

**6. POST `/me/avatar`** form-data：`file`（图片，JPG/PNG/GIF/WebP，≤5MB）→ `200` `{avatar: "/uploads/avatars/xxx.png"}`

### 群聊（7~11）

**7. GET `/groups/my`** → `200`：
```json
{"groups": [{"group_type": "DEPT", "group_id": 60, "name": "部门群·IT", "member_count": 6,
             "last_message": "...", "last_time": "2026-08-18 12:00:00"},
            {"group_type": "ALL", "group_id": 0, "name": "全员群聊", "member_count": 107, ...}]}
```

**8/10. GET `/groups/dept|all/messages?page&page_size`** → `200`：
```json
{"total": 12, "items": [消息对象, ...]}   // 按时间升序；部门群取本人部门
```

**9/11. POST `/groups/dept|all/messages`** body：`{content}`（1~2000 字）→ `200` `{message_id, created_at}`；**被禁言者 `403`「您已被禁言，暂时无法在群聊中发言」**；部门群须已分配部门

### 私聊（12~14）

**12. GET `/contacts`** → `200`：`[{EMPLOYEE_ID, name, DEPARTMENT_ID, role, avatar}]`（除本人外全部职员）

**13. GET `/private/messages?contact_id={id}&page&page_size`** → `200`：`{total, items}`（双方往来，按时间升序）

**14. POST `/private/messages`** body：`{receiver_id, content}` → `200` `{message_id, created_at}`（禁言不影响私聊）；发送后接收方未读数 +1

**14a. GET `/private/conversations`** → `200`：会话数组
```json
[{"EMPLOYEE_ID": 103, "name": "Alexander Hunold", "avatar": null, "role": "STAFF",
  "DEPARTMENT_ID": 60, "last_message": "在吗", "last_time": "2026-08-18 19:39:41", "unread_count": 2}]
```
按 `last_time` 降序（**最近消息置顶**），`unread_count` 用于红点提示

**14b. POST `/private/read`** body：`{contact_id}` → `200` `{message}`（清除该会话未读，红点消失）

**14c. GET `/private/unread-total`** → `200`：`{total}`（全部会话未读总数，供侧边栏「私聊」红点）

### 禁言（15~17，管理层）

**15. GET `/mutes`** → `200`：禁言中记录数组（见「禁言对象」）

**16. POST `/mutes`** body：`{employee_id, reason, mute_minutes?}`（`mute_minutes` 空=永久）→ `200` `{mute_id, message}`；越权 `403`（管理部门仅可禁言普通职员；总裁可含管理层；不可禁言本人/总裁）

**17. DELETE `/mutes/{mute_id}`** → `204`

### 总裁管理（18~20）

**18. GET `/managers`** → `200`：`[{EMPLOYEE_ID, name, role, DEPARTMENT_ID}]`（MANAGER+PRESIDENT）

**19. POST `/managers`** body：`{employee_id}` → `200` `{message}`；目标须为普通职员

**20. DELETE `/managers/{employee_id}`** → `200` `{message}`；目标须为管理部门职员（总裁不可撤销）

### 员工管理 / 统计（21~30，管理层）

- **21 GET `/employees/search`**：组合查询 + 分页，条件间 AND、`keyword` 内 OR
  - 参数：`keyword`（名/姓/邮箱模糊）、`department_id`、`job_id`、`min_salary`、`max_salary`、`hire_date_start`、`hire_date_end`、`page`、`page_size`
  - → `{total, page, page_size, items}`（items 含 `ROLE`、`AVATAR`）
- **22 GET `/employees`**：`skip`/`limit` 分页 → 员工数组
- **23 GET `/employees/{id}`** → 员工对象；`404`「员工不存在」
- **24 POST `/employees`**：新增普通职员（body 同原员工字段）；后端自动生成编号、账号=姓名、初始密码 `123456`、角色 `STAFF`；**姓名重复 `400`**
- **25 PUT `/employees/{id}`**：只更新传入字段；操作范围受限（管理部门仅普通职员，总裁可含管理层）
- **26 DELETE `/employees/{id}`** → `204`；范围限制同上
- **27 GET `/find/{name}`**：按名模糊查找
- **28/29 GET `/departments`、`/jobs`**：部门/职位字典（按 ID 排序）
- **30 GET `/overview`**：仪表盘统计
  - → `{total_employees, total_departments, total_jobs, avg_salary, max_salary, min_salary,
        department_stats[], job_stats[], hire_year_distribution[]}`

## 四、数据对象

**用户对象（user / /auth/me）**

| 字段 | 类型 | 说明 |
|---|---|---|
| EMPLOYEE_ID | int | 员工编号 |
| name | string | 姓名（登录账号） |
| FIRST_NAME / LAST_NAME | string | 名 / 姓 |
| EMAIL / PHONE_NUMBER | string? | 邮箱 / 电话 |
| role | string | STAFF / MANAGER / PRESIDENT |
| avatar | string? | 头像路径 `/uploads/avatars/xxx.png` |
| JOB_ID | string? | 职位 ID |
| DEPARTMENT_ID | int? | 部门 ID |

**消息对象（群聊/私聊 items）**

| 字段 | 类型 | 说明 |
|---|---|---|
| message_id | int | 消息 ID |
| group_type / group_id | ? | 群聊为 DEPT/ALL 与群标识；私聊为 null |
| sender_id | int | 发送者编号 |
| sender_name | string | 发送者姓名 |
| sender_avatar | string? | 发送者头像 |
| receiver_id | int? | 私聊接收者；群聊为 null |
| content | string | 内容 |
| created_at | string | `YYYY-MM-DD HH:MM:SS` |

**禁言对象（/mutes）**

| 字段 | 类型 | 说明 |
|---|---|---|
| mute_id | int | 记录 ID |
| employee_id / employee_name | int/string | 被禁言者 |
| operator_id / operator_name | int/string | 操作者 |
| reason | string | 原因 |
| mute_until | string? | 截止时间；null=永久 |
| created_at | string | 禁言时间 |

## 五、前端调用示例（`src/api/index.js`）

```js
authApi.login({ username: '207', password: '123456' })        // 登录（编号/姓名）
chatApi.myGroups()                                            // 我的群聊
chatApi.sendDept('大家好')                                     // 发部门群消息
chatApi.privateMessages({ contact_id: 100, page: 1 })         // 私聊历史
chatApi.conversations()                                        // 会话列表(含未读,新消息置顶)
chatApi.markRead(100)                                          // 标记已读
chatApi.unreadTotal()                                          // 未读总数(侧边栏红点)
muteApi.create({ employee_id: 103, reason: '违规', mute_minutes: 60 })
managerApi.grant(103)                                          // 总裁授予管理权限
profileApi.uploadAvatar(file)                                  // 上传头像
```

> Axios 已封装：自动携带 token、401 自动跳登录页、统一错误 message。生产环境需将 `/api` 与 `/uploads` 反代到 8000。
