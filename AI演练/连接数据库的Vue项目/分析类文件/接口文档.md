# 职工信息管理系统 — 接口文档

> 版本 V1.0 · 2026-08-18

## 一、通用说明

- **Base URL**：`http://127.0.0.1:8000/api/v1`　·　**数据格式**：JSON　·　**编码**：UTF-8　·　**认证**：无
- **路径参数**：`{xxx}`；所有接口前缀统一为 `/api/v1`
- **成功**：200 / 201 / 204（删除，空响应体）　**失败**：统一 `{ "code": <HTTP码>, "message": "<中文提示>" }`

**错误码**

| 状态码 | 场景 | message 示例 |
|---|---|---|
| 404 | ID 不存在 | `员工不存在` |
| 422 | 参数缺失/类型非法 | `请求参数校验失败`（附 `detail` 明细） |
| 500 | 服务器内部异常 | `服务器内部错误` |

## 二、接口一览

| # | 方法 | 路径 | 说明 |
|---|---|---|---|
| 1 | POST | `/employees` | 新增员工 |
| 2 | GET | `/employees` | 基础分页列表 |
| 3 | GET | `/employees/search` | 组合条件查询 + 分页 |
| 4 | GET | `/employees/{employee_id}` | 按 ID 查询 |
| 5 | PUT | `/employees/{employee_id}` | 更新员工 |
| 6 | DELETE | `/employees/{employee_id}` | 删除员工 |
| 7 | GET | `/find/{employee_FIRST_NAME}` | 按名模糊查找 |
| 8 | GET | `/departments` | 部门列表 |
| 9 | GET | `/jobs` | 职位列表 |
| 10 | GET | `/overview` | 仪表盘总览统计 |

## 三、接口详解

### 1. 新增员工　`POST /employees`

说明：`EMPLOYEE_ID` 由后端自动生成（当前最大编号 + 1），无需、不可传入。

**请求体**（`*` = 必填）：

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| `FIRST_NAME` * | string | 1~50 | 名 |
| `LAST_NAME` * | string | 1~50 | 姓 |
| `EMAIL` * | string | 1~50 | 邮箱 |
| `PHONE_NUMBER` * | string | 1~50 | 联系电话 |
| `HIRE_DATE` * | string(date) | `YYYY-MM-DD` | 入职日期 |
| `JOB_ID` * | string | 1~20 | 职位 ID |
| `SALARY` * | float | > 0 | 薪资 |
| `COMMISSION_PCT` | float | ≥ 0 | 提成比例（小数，0.15=15%） |
| `MANAGER_ID` | int | — | 直属上级编号 |
| `DEPARTMENT_ID` | int | — | 所属部门 ID |

**成功**：`201` → 员工对象（见「员工对象」）

### 2. 基础分页列表　`GET /employees`

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `skip` | int | 0 | 偏移量 |
| `limit` | int | 20 | 条数上限 |

**成功**：`200` → 员工对象数组

### 3. 组合查询 + 分页　`GET /employees/search`（列表页主接口）

条件间为 AND 关系；`keyword` 内为 OR 语义。

| 参数 | 类型 | 说明 |
|---|---|---|
| `keyword` | string | 模糊匹配 名/姓/邮箱 |
| `first_name` / `last_name` | string | 名/姓模糊匹配 |
| `department_id` | int | 部门精确 |
| `job_id` | string | 职位精确 |
| `min_salary` / `max_salary` | float | 薪资区间（含） |
| `hire_date_start` / `hire_date_end` | string | 日期区间（含，`YYYY-MM-DD`） |
| `page` | int | 页码（≥1，默认 1） |
| `page_size` | int | 每页条数（1~100，默认 10） |

**成功**：`200` → 分页对象：`{ total: int, page: int, page_size: int, items: 员工对象[] }`
（`page` 不足 1 取 1；`page_size` 超 100 截断为 100）

### 4. 按 ID 查询　`GET /employees/{employee_id}`

- 路径参数 `employee_id`（int）　**成功**：`200` → 员工对象　**失败**：404

### 5. 更新员工　`PUT /employees/{employee_id}`

- 路径参数 `employee_id`（int）
- **请求体**：员工对象字段，**全部可选**，只更新传入字段
- **成功**：`200` → 更新后员工对象　**失败**：404

### 6. 删除员工　`DELETE /employees/{employee_id}`

- 路径参数 `employee_id`（int）　**成功**：`204`（空响应体）　**失败**：404

### 7. 按名模糊查找　`GET /find/{employee_FIRST_NAME}`

- 路径参数：名关键字（需 URL 编码）
- **成功**：`200` → 员工对象数组（匹配 `FIRST_NAME`）

### 8. 部门列表　`GET /departments`

**成功**：`200` → 部门对象数组（按 `DEPARTMENT_ID` 升序）

### 9. 职位列表　`GET /jobs`

**成功**：`200` → 职位对象数组（按 `JOB_ID` 升序）

### 10. 仪表盘总览　`GET /overview`

**成功**：`200` →

```json
{
  "total_employees": 107,
  "total_departments": 27,
  "total_jobs": 19,
  "avg_salary": 6461.83,
  "max_salary": 24000.0,
  "min_salary": 2100.0,
  "department_stats": [{ "department_id": 10, "department_name": "Administration", "count": 1, "avg_salary": 4400.0 }],
  "job_stats": [{ "job_id": "SA_REP", "job_title": "Sales Representative", "count": 30 }],
  "hire_year_distribution": [{ "year": "1987", "count": 2 }]
}
```

- 基础指标：员工/部门/职位总数、平均/最高/最低薪资（平均保留 2 位小数）
- `department_stats[]`：部门人数 + 平均薪资；按 ID 升序，未分配（null）排最后；`department_name` 缺失回退「未分配」或「部门{id}」
- `job_stats[]`：职位人数；按人数降序；`job_title` 缺失回退为 `job_id`
- `hire_year_distribution[]`：入职年份（取日期前 4 位）分布，按年份升序

## 四、数据对象

### 员工对象

| 字段 | 类型 | 说明 |
|---|---|---|
| `EMPLOYEE_ID` | int | 员工编号（只读，后端生成） |
| `FIRST_NAME` / `LAST_NAME` | string | 名 / 姓 |
| `EMAIL` / `PHONE_NUMBER` | string | 邮箱 / 联系电话 |
| `HIRE_DATE` | string | 入职日期 `YYYY-MM-DD` |
| `JOB_ID` | string | 职位 ID |
| `SALARY` | float | 薪资 |
| `COMMISSION_PCT` | float? | 提成比例（小数） |
| `MANAGER_ID` | int? | 直属上级编号 |
| `DEPARTMENT_ID` | int? | 所属部门 ID |

### 部门对象

| 字段 | 类型 | 说明 |
|---|---|---|
| `DEPARTMENT_ID` | int | 部门 ID |
| `DEPARTMENT_NAME` | string | 部门名称（英文原值） |
| `MANAGER_ID` | int? | 部门经理编号 |
| `LOCATION_ID` | int? | 位置 ID |

### 职位对象

| 字段 | 类型 | 说明 |
|---|---|---|
| `JOB_ID` | string | 职位 ID |
| `JOB_TITLE` | string | 职位名称（英文原值） |
| `MIN_SALARY` / `MAX_SALARY` | int? | 职位薪资区间 |

## 五、前端调用（Axios 封装于 `src/api/index.js`，baseURL `/api/v1`）

```js
employeeApi.search({ page: 1, page_size: 10, keyword: 'king' })  // 组合查询+分页
employeeApi.create({ FIRST_NAME: 'John', ... })                   // 新增
employeeApi.update(208, { SALARY: 9500 })                         // 部分更新
employeeApi.remove(208)                                           // 删除
dictionaryApi.getOverview()                                       // 总览统计
```

> 生产环境需配置 `/api` → 后端的反向代理。
