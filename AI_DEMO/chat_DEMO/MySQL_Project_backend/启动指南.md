# 🚀 职员工作群聊系统 · 启动指南

> 本指南覆盖：**快速启动**、**彻底关闭**、**重启** 三步，照着复制命令就能跑。

---

## ✅ 零、启动前检查（3 秒）

1. **MySQL 已启动**：后端连的是 `127.0.0.1:3306` 的 `my-first-sql` 库，MySQL 没开的话后端会报数据库连接错误。首次启动会自动建表，不用手动建。
2. **前端依赖已装好**：`node_modules` 目录存在即可（没有就先跑一次 `npm install`）。
3. **Python 环境**：使用项目自带的虚拟环境，路径在 `my_python_work_myself\.venv`。

---

## ⚡ 一、快速启动（核心）

> 需要 **两个终端窗口**，一个跑后端、一个跑前端。

### 终端 1：启动后端（端口 8000）

```bash
cd "C:\shoolwork\my_python_work_myself\AI演练\职员工作群聊项目\MySQL_Project_backend"
C:\shoolwork\my_python_work_myself\.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

看到类似 `Uvicorn running on http://127.0.0.1:8000` 即启动成功。

### 终端 2：启动前端（端口 5173）

```bash
cd "C:\shoolwork\my_python_work_myself\AI演练\职员工作群聊项目"
npm run dev
```

看到 `Local: http://localhost:5173/` 即启动成功。

### 打开页面

浏览器访问 👉 **http://localhost:5173**

> ⚠️ **必须用 `localhost`，不要用 `127.0.0.1`** —— 前端只绑定了 IPv6 回环，用 `127.0.0.1` 会打不开。

## 🛑 二、彻底关闭项目

### 方式 A：一键按端口关闭（推荐，安全、不误杀其他程序）

复制下面这段到 **PowerShell** 里执行，会只关掉占用 `8000`（后端）和 `5173`（前端）的进程，本机其他程序（如 openclaw 网关）不受影响：

```powershell
$ports = 8000, 5173
foreach ($p in $ports) {
  Get-NetTCPConnection -LocalPort $p -State Listen -ErrorAction SilentlyContinue |
    Select-Object -ExpandProperty OwningProcess -Unique |
    ForEach-Object { Stop-Process -Id $_ -Force; Write-Host "已关闭占用端口 $p 的进程 (PID=$_)" }
}
```

### 方式 B：按 PID 手动关闭

先用命令查出当前 PID（每次重启 PID 会变，别用写死的），再逐个关闭：

```bash
tasklist //FI "IMAGENAME eq python.exe"   # 查后端 PID
tasklist //FI "IMAGENAME eq node.exe"     # 查前端 PID
taskkill //PID <要关的PID> //F            # 把查到的 PID 填进去
```

> ⚠️ **不要用 `taskkill //F //IM node.exe` 一刀切** —— 本机还有其他 node 进程（如 openclaw 网关），会被误杀。按 PID 精确关最稳妥。

## 🔄 三、重启（改完代码要重启时）

1. 先执行上面 **第二步「彻底关闭」**；
2. 确认终端里后端、前端都已退出（或直接看到两个窗口的进程结束）；
3. 再回到 **第一步「快速启动」** 重新跑即可。

> 💡 小提示：后端用的是 `--reload`，改后端代码会自动重载，不用手动重启；改前端代码 Vite 会自动刷新页面。

---

## ❓ 常见问题

| 现象 | 原因 / 解决办法 |
|---|---|
| 后端报 `address already in use` | 端口 8000 被旧进程占用，先执行第二步彻底关闭再启动 |
| 前端报 `Port 5173 is already in use` | 同上，先彻底关闭再启动 |
| 页面打不开 | 确认用的是 `http://localhost:5173`，且两个终端都在运行 |
| 后端报数据库连接错误 | MySQL 服务没启动，先打开 MySQL 再跑后端 |
