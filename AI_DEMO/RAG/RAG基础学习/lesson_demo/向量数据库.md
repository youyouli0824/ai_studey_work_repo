## chroma的工作模式：内存模式、<font style="color:#DF2A3F;">持久化模式</font>
**<font style="color:#df2a3f;">内存模式客户端</font>****：**

> + 数据全部保存在内存里，**<font style="color:#df2a3f;">不会写入磁盘</font>**；
> + 程序运行期间向量、文档正常可用；
> + 一旦程序终止、进程关闭，所有数据直接丢失；
> + 适合**临时测试、课堂Demo**，不能用于正式持久化场景。
>

**<font style="color:#DF2A3F;">持久化模式客户端</font>**：

> + `<font style="background-color:rgba(0, 0, 0, 0.06);">path=r"./db/chroma"</font>` 指定本地文件夹路径；
> + 向量、文档、索引会自动保存到磁盘目录；
> + 重启程序后，重新连接同一个路径，数据不会丢失；
> + **开发、生产环境**推荐使用持久化模式。
>

```python
# 获取一个内存模式的客户端
client=chromadb.Client()

# 持久化客户端
client=chromadb.PersistentClient('保存数据的路径')
```

## chroma常见方法
### 3.1 add()
用于向集合中**批量添加文档、向量与唯一编号**。<font style="color:#df2a3f;">如果</font>**<font style="color:#df2a3f;">ID重复会直接报错，新增不可重复主键</font>**<font style="color:#df2a3f;">。</font>

```python
# 将向量存入集合中
collection.add(documents=["Article by john", "Article by Jack", "Article by Jill"],
    embeddings=[[1, 2, 3], [4, 5, 6], [7, 8, 9]],
    ids=["1", "2", "3"])
```

### 3.2 update()
该方法用于根据已有的ID更新文档、向量。**<font style="color:#df2a3f;">只能更新已存在的ID，不存在的不会更新</font>**<font style="color:#df2a3f;">。</font>

```python
# 修改向量:在更新向量时，要求必须指定要更新的向量的id；更改的是向量
collection.update(documents=["Article by john", "Article by Jack", "Article by Jill"],
     embeddings=[[10, 20, 30], [4, 5, 6], [7, 8, 9]],
     ids=["1", "2", "3"])
```

### 3.3 get()
精确过滤、关键词匹配，<font style="color:#df2a3f;">不计算向量相似度</font>；适合管理数据(增删改配套使用)。get默认不返回向量，调试向量数据时必须加上`<font style="background-color:rgba(0, 0, 0, 0.06);">include=["embeddings"]</font>`

```python
# 带向量的全量查询
results = collection.get(include=['embeddings'])
print(results)

# select * from my_collection where documents like '%john%'
results2 = collection.get(include=['embeddings'],where_document={'$contains':'john'})
print(results2)
```

### 3.4 query()
`<font style="color:#df2a3f;background-color:rgba(0, 0, 0, 0.06);">query()</font>`：语义检索，输入向量，自动查找语义相近的TopN个向量

```python
# 查询向量，返回距离最近的2个向量
res=collection.query(query_embeddings=[4, 5, 6],n_results=2)
print(res.get('documents')[0])
```

### 3.5 delete()
用于根据ID或者文本条件删除记录。

```python
# 把id为1的向量删除掉
collection.delete(ids=["1"])
```

### 3.6 get与query的区别
get(): 是精确查询、关键词匹配，默认不返回向量，不能进行相似度计算。适合普通的增删改查；如果想调试向量，需要通过include=['embeddings']

query()：语义检索查询，可以根据向量来查询，可以返回与语义最相近的Top N个向量。

## Chroma+LLM工作流程
Chroma内部保存了两组核心数据：

> + **Documents(原始文本)**：即知识库切片后的原文(示例`<font style="background-color:rgba(0, 0, 0, 0.06);">Call me Ishmael...</font>`）
> + **Embeddings(向量)**：文本经过Embedding模型转换得到的高维浮点数组(示例`<font style="background-color:rgba(0, 0, 0, 0.06);">[1.0, 2.1, 3.4 ...]</font>`)
>

**<font style="color:#df2a3f;">每一条文档和它对应的向量一一绑定、成对存储。</font>****Chroma不只是单纯存向量，同时也维护了原始文本、元数据。****<font style="color:#df2a3f;">在检索命中了向量后，可以直接取出对应的原文，供大模型使用。</font>**上图展示了**基于Chroma向量数据库的简易RAG检索完整链路**，我们自上而下拆解整条数据流：

<img src="https://cdn.nlark.com/yuque/0/2026/png/21742863/1786351240849-5adc80f0-71ef-4746-8a87-729875221d70.png" width="900" title="" crop="0,0,1,1" id="YmnBc" class="ne-image">

1. 程序要接受用户的问题；
2. 用户的问题变成向量，使用embedding向量模型转为问题向量；
3. 把问题向量传递给Chroma，在库内进行相似度检索；
4. Chroma找到了Top N个相近的原文document，返回给上层；
5. 把找到的内容，与Prompt提示词组装，传递给LLM Context上下文 Window；
6. 把封装好的Prompt(检索到的向量+用户问题)，传递给LLM，最终生成答案

### 5.1 向量数据库连接器类
在该类中，负责将文本转向量，将向量入库，并实现向量查询检索。

```python
# 定义一个RAG知识库类，负责管理向量库的增删改查
class MyVectorDBConnector:
    # 构造方法：在构造方法中进行初始化
    def __init__(self, collection_name):
        self.openai = OpenAI(api_key=os.getenv("DASHSCOPE_API_KEY"),
                             base_url=os.getenv("DASHSCOPE_BASE_URL"))
        chroma_client=chromadb.PersistentClient("./chroma_db")
        self.collection_name = chroma_client.get_or_create_collection(name=collection_name)

    # 负责把文档变成向量
    def get_embedding(self,text, model_name="text-embedding-v4"):
        # 获取一个embedding模型，用该模型将text转为向量
        data = self.openai.embeddings.create(input=text, model=model_name).data
        return [x.embedding for x in data]

    # 将文档变成向量，并添加到向量库
    def add_document(self, documents):
        embeddings = self.get_embedding(documents)
        self.collection_name.add(embeddings=embeddings,
            documents=documents,
            # 为每个文档生成一个唯一的ID
            ids=[f"id{i}" for i in range(len(documents))])

    # 从向量库中查询
    def search(self,query,top_n):
        # 将查询文本转换为向量
        query_embedding = self.get_embedding([query])
        results = self.collection_name.query(
            query_embeddings=query_embedding,
            n_results=top_n
        )
        return results
```

### 5.2 封装大模型聊天机器人类
该类负责接收用户的问题，将问题变成向量，并将问题与检索到的参考答案，拼接成prompt提示词，最终生成答案。

```python
# 全局固定提示词模板（解决类内无法读取的作用域bug）
prompt_template = """
你是一个问答机器人。
你的任务是根据下述给定的已知信息回答用户的问题。
确保你的回复完全依据下述已知信息，不要编造答案。
如果下述已知信息不足以回答用户的问题，请直接回复"我无法回答您的问题"。

已知信息:
__INFO__

用户问题：
__QUERY__

请用中文回答用户的问题。
"""

#封装一个大模型的聊天机器人类
class MyChatBot:
    def __init__(self, vector_db, n_results=2):
        self.vector_db = vector_db
        self.n_results = n_results
        self.openai = OpenAI(api_key=os.getenv("DASHSCOPE_API_KEY"),
                             base_url=os.getenv("DASHSCOPE_BASE_URL"))

    # 将提示词丢给大模型，大模型回答
    def get_chat_completion(self,prompt,model="qwen-plus"):
        messages = [{"role": "user", "content": prompt}]
        response=self.openai.chat.completions.create(model=model,messages=messages,temperature=0)
        # 从大模型中提取第一个答案
        return response.choices[0].message.content

    #接收用户的问题，大模型根据用户的问题，最终生成对应的答案
    def chat(self,user_query):
        # 把用户的问题向量化，根据该向量查询向量库中的文档
        search_results=self.vector_db.search(user_query,self.n_results)

        # 拼接检索上下文，每个文档之间用换行符隔开
        context = "\n".join(search_results['documents'][0])
        # print('context', context)
        # 填充模板
        prompt = prompt_template.replace("__INFO__", context).replace("__QUERY__", user_query)
        print("prompt",prompt)
        return self.get_chat_completion(prompt)
```

### 5.3 封装文本加载及切分函数
负责加载文档，并将文档分段切分。

```python
# 按照滑动窗口切割文档
def sliding_window_chunks(text, chunk_size, stride):
    # 挑选固定字符长度的文本片段
    return [text[i:i + chunk_size] for i in range(0, len(text), stride)]

# 从PDF文件中提取文字片段
def extract_text_from_pdf(filename, page_numbers=None):
    '''从PDF文件中（按指定页码）提取文字'''
    full_text = ''
    # extract_pages(filename)会返回一个列表，每个元素是一个页面的布局对象
    for i, page_layout in enumerate(extract_pages(filename)):
        # 跳过指定页码外的页面
        if page_numbers is not None and i not in page_numbers:
            continue
        # 遍历当前页中的所有元素
        for element in page_layout:
            # 判断当前元素是否为文本类型
            if isinstance(element, LTTextContainer):
                # 去除文本中的换行符和空格，拼接成连续的字符串
                full_text += element.get_text().replace("\n", "").replace(" ", "")
    text_chunks = sliding_window_chunks(full_text, 250, 100)
    return text_chunks
```
