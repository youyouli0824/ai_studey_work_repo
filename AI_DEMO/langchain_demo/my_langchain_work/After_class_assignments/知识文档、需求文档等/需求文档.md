## 一、业务背景（企业真实痛点）
某制造型企业拥有大量内部政策文档、员工手册、制度公告、业务规范网页，员工遇到制度咨询、流程查询问题时，存在如下痛点：

1. 文档分散在网页、本地文件，员工查找资料需要翻阅大量文档，检索效率极低；
2. 普通关键词搜索只能匹配文字，无法理解语义，经常搜不到相关制度；
3. 员工频繁咨询行政、HR，大量重复问答消耗人力；
4. 需要严格基于企业内部资料回答，禁止大模型幻觉编造不存在制度；
5. 部分问答需要固定输出格式（例如流程类问题输出步骤列表），直接写Prompt很难稳定约束输出格式。

**业务目标**：基于LangChain开发企业内部知识库RAG问答原型系统，员工输入自然语言问题，系统基于企业内部文档给出精准回答，减少人工咨询成本。

> 覆盖知识点：LangChain可组合性思想，组件积木式开发；模型、嵌入、工具、消息等核心组件；RAG完整链路；多种提示词模板。
>

## 三、功能需求
### 3.1 基础模块1：知识库构建模块（离线预处理模块）
1. 通过`WebBaseLoader`加载企业政策网页，过滤网页导航、广告等无关标签，只获取正文；
2. 使用`RecursiveCharacterTextSplitter`对文档进行语义分块，自定义块大小与重叠；
3. 使用DashScopeEmbeddings完成文档片段向量生成；
4. 将向量持久化保存到本地FAISS向量库文件夹`faiss_store`；

> 要求：代码解耦，加载、分割、向量化、存储拆分为独立函数。
>

### 3.2 基础模块2：知识库问答RAG核心模块
1. 读取本地已经构建完成的FAISS向量库；
2. 使用`ChatPromptTemplate`构建RAG聊天提示词，系统指令强制要求**只允许使用检索到的上下文回答问题，没有相关资料直接回复“知识库未查询到相关制度”，禁止编造内容**；
3. 使用`create_stuff_documents_chain`构建文档合并链，`create_retrieval_chain`组装完整RAG检索链；
4. 用户输入业务问题，执行检索链返回回答；输出两部分：①模型最终答案 ②检索到的参考文档来源（网页url）。

### 3.3 拓展模块3：多种提示词模板演示（必须全部实现）
1. **普通PromptTemplate**：接收文档片段，对文档片段生成简短摘要；
2. **ChatPromptTemplate聊天模板**：实现简单翻译小功能，演示system+human角色消息；
3. **FewShotPromptTemplate少样本模板**：针对流程类查询任务，提供2组输入输出样例，强制模型输出`1.xxx\n2.xxx`有序列表格式；

> 要求三个模板封装独立函数，可单独调用运行。
>

### 3.4 非功能需求（工程标准）
1. API‑KEY、base_url、模型名称、embedding模型名称全部配置在`.env`文件，代码中通过`dotenv`读取，**禁止密钥硬编码在代码**；
2. 捕获基础异常：向量库不存在、API调用失败给出友好提示；
3. 代码添加注释，关键位置标注对应LangChain组件知识点；
4. 不实现web页面，Python控制台运行原型即可。

## 四、代码开发规范（企业工程标准）
1. **依赖管理**：提供requirements.txt，版本和课程PDF保持一致

```plain
langchain==1.1.0
langchain-openai==1.1.0
langchain-community
langchain-text-splitters
faiss-cpu
python-dotenv
bs4
dashscope
```

2. **.env配置文件模板**，提交作业只提交模板，不提交真实密钥

```plain
DASHSCOPE_API_KEY=your_key_here
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen3.7-plus
EMBED_MODEL=text-embedding-v4
```

3. **代码结构规范**

```plain
project/
├── .env.example        # 环境变量模板
├── requirements.txt    # 依赖清单
├── build_knowledge.py  # 模块1：知识库构建、网页加载、向量化入库
├── rag_chat.py         # 模块2：RAG检索问答主逻辑
├── prompt_demo.py      # 模块3：三类提示词模板演示代码
└── faiss_store/        # FAISS向量库运行生成，不要提交到作业压缩包
```

4. 编码规范：函数命名使用蛇形命名，每个函数写简短文档字符串，关键代码行注释标注对应课程知识点；禁止大段无注释代码。
